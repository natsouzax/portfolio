This repository contains my personal portfolio.

# Performance Philosophy

Visual quality should never compromise usability.

Target:

- Smooth scrolling
- Stable animations
- Excellent Lighthouse scores
- Responsive interactions
- Fast loading
- Efficient rendering

Every animation should justify its rendering cost.

---

# Accessibility

Accessibility is a feature.

Not an afterthought.

Support:

- prefers-reduced-motion
- keyboard navigation
- focus visibility
- semantic HTML
- screen readers
- sufficient color contrast

The experience should remain enjoyable even with animations disabled.

---

# Technical Philosophy

Architecture comes before implementation.

Maintainability comes before cleverness.

Readability comes before shortcuts.

Scalability comes before hacks.

Every component should have a clear responsibility.

Avoid duplication.

Prefer composition over complexity.

---

# Continuous Improvement

Never assume the first solution is the best.

Whenever implementing a feature:

1. Understand the problem.
2. Analyze the current architecture.
3. Evaluate alternatives.
4. Choose the best approach.
5. Implement.
6. Validate.
7. Refine.
8. Optimize.

Iteration is expected.

Perfection is approached through refinement.
